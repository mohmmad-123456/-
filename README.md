## ساخت APK با GitHub Actions

۱. یک مخزن GitHub بسازید. فایل ZIP را استخراج و **محتویات پوشهٔ ConsentCamera** را در ریشهٔ مخزن قرار دهید، نه خود آن پوشه یا فایل ZIP را.

۲. ریشهٔ مخزن باید شامل `.github/workflows/build-apk.yml`، `android` و `bot` باشد. پوشهٔ `.github` ممکن است در مدیریت فایل مخفی باشد؛ مطمئن شوید آن را هم آپلود می‌کنید.

۳. فایل‌ها را روی شاخهٔ `main` یا `master` ثبت کنید. گردش‌کار با ثبت تغییر اجرا می‌شود؛ برای اجرای دستی، در زبانهٔ Actions گردش‌کار **Build consent camera APK** را باز کنید و **Run workflow** را بزنید. اگر Actions غیرفعال است، آن را در تنظیمات مخزن فعال کنید.

۴. پس از موفقیت اجرای گردش‌کار، همان اجرا را باز کنید. از قسمت **Artifacts** فایل **ConsentCamera-debug-APK** را دانلود و استخراج کنید. داخل آن `app-debug.apk` قرار دارد. برای دانلود ممکن است لازم باشد وارد حساب GitHub شوید.

۵. APK را فقط روی گوشی خودتان برای آزمایش نصب کنید. در صورت نیاز مجوز نصب از منبع انتخاب‌شده را در تنظیمات اندروید فعال کنید.

## نکات مهم

* این بسته سورس و گردش‌کار ساخت است، نه APK ساخته‌شده. گردش‌کار اینجا روی GitHub اجرا نشده و موفقیت ساخت هنوز تأیید نشده است.
* نیازی به وارد کردن توکن تلگرام در GitHub نیست. ساخت APK و آزمون بات بدون توکن انجام می‌شوند.
* خروجی، **نسخهٔ debug برای آزمایش** است، نه نسخهٔ انتشار. کلید debug در اجراهای تازه می‌تواند تغییر کند؛ در این صورت نصب روی نسخهٔ قبلی ممکن است نیاز به حذف آن داشته باشد. حذف برنامه کش محلی را پاک می‌کند.
* GitHub Actions بات را به‌صورت دائمی میزبانی نمی‌کند. بات پایتون را جداگانه روی رایانه یا سرور خودتان اجرا کنید.
* گرفتن عکس و اشتراک‌گذاری فقط با اقدام صاحب گوشی است. دکمهٔ تلگرام صرفاً پیام درخواست ارسال می‌کند.
* سقف مصرف و هزینهٔ Actions به حساب و مخزن شما بستگی دارد. خروجی‌های این گردش‌کار ۷ روز نگه داشته می‌شوند.
